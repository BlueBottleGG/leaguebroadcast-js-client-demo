Dummy camera publisher — each tile pushes one fake webcam stream to VDO.Ninja. Keep this window open while testing. Query params: ?prefix=broadcastCam&count=10&server=https://vdo.ninja. Launch the browser with --use-fake-device-for-media-stream --use-fake-ui-for-media-stream (see tools/start-dummy-cameras.ps1) so no real webcam or permission prompt is needed. Streams publish with &chunked by default (so the overlay's ?camdelay can buffer past ~4s); add &chunked=off for the standard RTP path.
